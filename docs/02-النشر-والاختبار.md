6. **انشر من الجهاز**:
   ```
   cd ~/repo && tar xzf "$HOME/mnt/ayman/المرجع الفني/update<N>.tgz" && git add -A \
   ```

8. **افحص الموقع الحي** بسرعة عبر Chrome (صفحة واحدة تكفي)، ثم **اشرح للمستخدم** ما سيلاحظه.

## الاختبار المحلي

- **خادم محلي**: `cd /home/claude/platform/site && (setsid nohup python3 -m http.server 8123 >/dev/null 2>&1 &)`.
- **محاكي Supabase** (يُحقن بدل مكتبة supabase-js عبر Playwright): `mock_supabase.mjs` + بيانات `mockdb.json` في مجلد الجلسة الأصلية (`scratchpad`). إن لم يكن موجوداً في جلسة جديدة فأنشئ محاكياً مبسطاً يدعم: `from().select/insert/update/upsert/delete`، المرشحات `eq/neq/in/gte/lte/is/not/order/range/limit/single/maybeSingle`، الروابط `projects(...)`, `variants(...)`, `change_orders(...)`، وتخزين وهمي و`rpc`. المستخدم الوهمي `u1` بدور admin.
- **نمط سكربت Playwright**: يُحمّل `mockdb.json`، يحقن `window.__MOCKDB` و`window.AHC_CONFIG` عبر `addInitScript`، ويعترض `**/@supabase/supabase-js@2/+esm` و`**/config.js`، ثم يفتح `http://127.0.0.1:8123/#/route` ويلتقط صوراً بمقاسي اللابتوب (1400×900) والآيفون (`devices['iPhone 13']`)، ويجمع أخطاء الصفحة.
- **PostgreSQL محلي 16** لاختبار الترحيلات: بيانات في `/tmp/pgtest/data` منفذ 5499 مقبس `/tmp` قاعدة `t`؛ تشغيل: `su postgres -c "/usr/lib/postgresql/16/bin/pg_ctl -D /tmp/pgtest/data -o '-p 5499 -k /tmp' -l /tmp/pgtest/pg.log start"`. محاكاة مستخدم: `set role authenticated; select set_config('request.jwt.claim.sub','<uuid>',false);` (مستخدمان تجريبيان: `1111…` admin و`2222…` engineer). في جلسة جديدة يلزم إعادة إنشائه بتشغيل الترحيلات بالترتيب مع stub لمخطط `storage` ودوال `auth.uid()`.
- **الأداء**: كل الحركات opacity/transform فقط؛ قِس بـ `PerformanceObserver('longtask')` عند الشك.

## أعراف الكود

- الرسائل والواجهة كلها بالعربية؛ التواريخ بـ `dateAr()` (ميلادي بأرقام لاتينية)؛ المبالغ بـ `money_inp` (تقبل الفواصل والكسور) و`money()` للعرض.
- الدوال المعرّضة للتلاعب تُحمى في قاعدة البيانات (RLS/Guard triggers) لا في الواجهة.
- الإشعارات تُنشأ بدالة `notify(users[], kind, title, body, link)` في DB؛ الفحوص اليومية تمنع التكرار خلال 7 أيام بالبحث في `notifications` بنفس الرابط.
- سجل الإنجازات `v_user_activity` يُعاد إنشاؤه كاملاً في آخر ترحيل يعدّله (انسخ التعريف الأخير كاملاً ثم أضف الأسطر الجديدة).
- عند إضافة جدول جديد: `enable row level security` + سياسات + `grant ... to authenticated` + `grant usage on sequence`.
