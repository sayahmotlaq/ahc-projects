# بنية المنصة

## التقنية

- **واجهة**: تطبيق صفحة واحدة بلا إطار عمل (Vanilla ES Modules) + موجّه بالـ hash (`#/route`). ملفات: `site/index.html`, `site/app.css`, `site/js/*.js`, `site/sw.js` (Service Worker للإشعارات)، `site/manifest.json` (PWA).
- **استضافة**: GitHub Pages (مجانية) من نفس المستودع، النشر تلقائي عبر GitHub Actions عند كل دفع إلى `main`.
- **قاعدة البيانات والمصادقة والتخزين**: Supabase (PostgreSQL + RLS + Storage + Edge Function `push` للإشعارات).
- **الإصدار**: يُحقن `site/config.js` وقت النشر بعنوان Supabase والمفتاح العام (anon) ومفتاح VAPID العام ورقم الإصدار (SHA)، وتُختم كل الاستيرادات بـ `?v=SHA` لكسر الكاش، ويظهر شريط «صدرت نسخة جديدة» تلقائياً.

## الأدوار

`admin` (مدير النظام — صالح)، `engineer` (مهندس مشاريع: ينشئ مشاريعه ويعدّل مشاريعه فقط)، `viewer` (قراءة)، `finance` (تسجيل الصرف في المستخلصات فقط)، `clerk` (إداري: اطلاع + طباعة + رفع مستندات فقط)، `pending`، `disabled`.
دوال DB: `my_role()`, `is_admin()`, `can_edit()` (admin/engineer), `can_read()`, `can_docs()` (admin/engineer/clerk), `is_finance()`. الصلاحيات مطبّقة في قاعدة البيانات (RLS + Guard triggers) لا في الواجهة فقط.

## قاعدة البيانات (الترحيلات بالترتيب، كلها idempotent)

`0001` المخطط الأساسي والمرجع الفني · `0002` امتدادات المشاريع والتحديات · `0003` المهام والطلبات · `0004` النشاط · `0005` المستخلصات ودور المالية · `0006` التقارير الفنية والصور · `0007` المستندات/المخططات/الاعتمادات · `0008` ربط الاعتماد ببند الكميات · `0009` الإشعارات + Push + `notify_stale_projects()` · `0010` `v_user_activity` · `0011` ملكية المشاريع وربطها بالمهندسين · `0012` المشروع بعد «استلام ابتدائي» منتهٍ ولا يُعد متأخراً · `0013` دور الإداري · `0014` الملخص اليومي `daily_digest()` · `0015` أوامر التغيير والإغلاق والضمان · `0016` الجدول الزمني (`sched_calc`, `sync_schedule_progress`, `shift_schedule`, `notify_late_milestones`) · `0017` التحديات (درجة محسوبة، `challenge_notes`, `tasks.challenge_id`, `notify_overdue_challenges`) · `0018` التقرير المشارك (`shared_reports`, `shared_notes`, دالتا `get_shared_report`/`add_shared_note` للزائر anon) · `0019` التقويم (`cal_feed`, رمز الاشتراك) · `0020` البنود الحرة في جدول الكميات (`boq_lines.kind`, تسعير/إخفاء الأسعار) · `0021` قائمة بنود المقطوعية والنطاقات (`ls_items`, `ls_templates`) · `0022` الأثاث غير الطبي · `0023` غرف التنويم · `0024` حزمة الطرح (مستندات/مخططات الطرح) · `0025` بند الرسومات التنفيذية · `0026` الإجازات والتغطية (`leaves`, `holidays`, `leave_balances`, `notify_leave_events`) · `0027` رسائل اليوم (`messages`, `message_reads`, `notify_scheduled_messages`) · `0028` سلاسل المتابعة (`comments`, `v_thread`) · `0029` العروض التنفيذية (`briefs`, `brief_items`, `brief_notes`, `get_brief`, `add_brief_note`) · `0030` مسارا المشتريات والمالية والتحدي في `brief_items`.

قواعد مهمة: `profiles.role` له قيد check يجب تحديثه عند إضافة دور. الترحيلات تُنفَّذ بلا معاملة واحدة لكل ملف، لذا يجب أن تكون قابلة لإعادة التشغيل (`if not exists`, `drop ... if exists`).

## المهام المجدولة (GitHub Actions)

- `deploy.yml`: عند كل دفع + جدولان يومياً (04:45 و12:30 UTC). الوظائف: تشغيل الترحيلات → البذر والاستيراد → خطوة SQL يومية (`notify_stale_projects`, `sync_schedule_progress`, `notify_late_milestones`, `notify_overdue_challenges`, `notify_leave_events`, `notify_scheduled_messages`) → الملخص اليومي (`daily_digest` صباح/مساء بحسب الساعة) → نشر السجلات في فرع `logs` (`logs/seed.txt`) → نشر الموقع → نشر Edge Function عند تفعيل المتغير `DEPLOY_FUNCTIONS=yes`.
- `backup.yml`: كل جمعة 02:00 UTC ويدوياً: pg_dump + Excel + JSON مشفّر → المستودع الخاص `ahc-backups/weekly/` (يُحتفظ بآخر 12).
