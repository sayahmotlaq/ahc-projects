آخر تحديث لهذا المستند: 29 سبتمبر 2026. **آخر حزمة مسلَّمة: `update34.tgz`** (الحزمة التالية: update35). آخر التزام منشور: «الجوال: الجداول بطاقات، والنماذج صفحات كاملة بأزرار ثابتة».

## ما اكتمل ونُشر (بالترتيب الزمني تقريباً)

المشاريع والمراحل وجداول الكميات والمرجع الفني → المهام والطلبات → المستخلصات ودور المالية → التقارير بفترة زمنية ومنشئ مخصص → التقارير الفنية والمحاضر بالصور → المستندات والمخططات والاعتمادات → الإشعارات (جرس + Web Push + ملخص صباحي/مسائي) → إعادة التصميم v2 (قائمة جانبية، ثيم فاتح، ⌘K) → الأداء والإنجازات (تلقائي بلا تقييم يدوي) → المهندس ينشئ مشاريعه ويعدّلها فقط + ربط 17 مشروعاً بالمهندسين تلقائياً → المشروع بعد «استلام ابتدائي» منتهٍ → دور الإداري → صفحة «يومي» → حقول المبالغ الدقيقة → فاحص جودة البيانات → الإعدادات من الواجهة → تصدير Excel → نسخ احتياطي أسبوعي → أوامر التغيير والتمديدات مع مزامنة العقد → الإغلاق والضمان وتقييم المقاول والدروس → **الجدول الزمني والمعالم** (update30/31) → **إعادة بناء التحديات والمخاطر** (update32) → **الحركة والصقل** (update33) → **بطاقات ونماذج الجوال** (update34).

## قرارات مهمة يجب احترامها

- نسبة الإنجاز: لكل مشروع مصدر `progress_mode` = `manual` (افتراضي، الوضع الحالي) أو `schedule`. لا تُلغِ الإدخال اليدوي؛ التحول تدريجي بقرار المستخدم لكل مشروع.
- التحديات: لا تُغلق وفيها مهام مفتوحة؛ التكليف الحقيقي عبر المهام (المهام ينشئها admin فقط)، والمهندس يضيف متابعات.
- الأداء: رصد لإثبات الجهد لا للتقييم؛ لا طبقة تقييم يدوي ولا مجاملات. لوحة الشرف مطفأة افتراضياً.
- الإشعارات الخارجية (واتساب/بريد/Slack) مؤجلة بقرار المستخدم.
- دور المقاول مؤجل.
- الاستضافة تبقى GitHub Pages مجانية؛ الدومين يُشترى فقط (توصيتنا Cloudflare أو Namecheap، ويفضَّل سؤال تقنية المعلومات بالتجمع عن نطاق فرعي رسمي).

## القائمة المعلقة

1. **شكوى المهندسين من رفع المستندات**: الرفع يعمل لدى admin (مُختبر حياً). بانتظار صورة أو رسالة خطأ من مهندس. الاحتمالات: نسخة قديمة في الكاش، دور غير مناسب، حجم ملف > الحد (50MB للمستندات، 8MB للصور)، أو نوع ملف.
2. **الدومين**: عند شراء اسم، اضبط DNS (CNAME إلى `sayahmotlaq.github.io`) + إعداد Custom domain في GitHub Pages + تحديث روابط الإشعارات و`push` إن لزم.
3. **خطة Supabase Pro** (25$/شهر) عند اقتراب التخزين من 1GB أو الحاجة لنسخ احتياطي من المزوّد.
4. **تدوير الرموز** التي ذُكرت سابقاً في المحادثات (GitHub PAT، Supabase access token) — أمان.
5. بقية أقسام المرجع الفني (~780 بنداً لم تُستورد).
6. الوضع الليلي (مؤجل، عائد منخفض).
7. البحث الشامل عبر المستندات والمهام من لوحة ⌘K (حالياً المشاريع فقط).
