# اقرأ أولاً — منصة إدارة مشاريع تجمع الأحساء الصحي

هذا المستند هو نقطة البداية لأي محادثة جديدة في مشروع «التجمع». اقرأه كاملاً قبل أي عمل، ثم اقرأ بقية مستندات المشروع بحسب الحاجة:

- `01-بنية-المنصة.md` — ما الذي بُني، الملفات، قاعدة البيانات، الأدوار.
- `02-النشر-والاختبار.md` — كيف تُعدّل وتنشر وتتحقق (الإجراء الحرفي).
- `03-الحالة-والمعلق.md` — أين وصلنا، القرارات، والقائمة المعلقة.

## من المستخدم؟

**صالح المطلق** — رئيس قسم المشاريع، إدارة الخدمات الفنية، تجمع الأحساء الصحي. مديره: **أيمن**. يتحدث بالعامية السعودية ويحب الإجابات المباشرة والصريحة، ويهتم جداً بالتكلفة (لا تُشغّل وكلاء فرعيين أو أعمالاً غير ضرورية، اعمل اقتصادياً وادمج الأعمال في تحديث واحد).

## ما المشروع؟

منصة ويب لإدارة مشاريع القسم (دراسة → طرح → ترسية → تنفيذ → استلام → ضمان → إقفال) تُستخدم من الإدارة والمهندسين والمالية والإداريين، على اللابتوب والجوال (مضافة كتطبيق على الآيفون).

- الموقع الحي: https://sayahmotlaq.github.io/ahc-projects/
- المستودع (عام): https://github.com/sayahmotlaq/ahc-projects
- قاعدة البيانات: Supabase (مشروع `ejyebwykojqwsjkyriom`، فرانكفورت)
- النسخ الاحتياطي الأسبوعي: مستودع خاص `sayahmotlaq/ahc-backups`

## القواعد المتفق عليها (ملزمة)

1. **لا تستبدل ملفاً سُلِّم للمستخدم**؛ أي إصدار جديد يحمل رقماً جديداً (update35.tgz بعد update34.tgz، وهكذا). آخر رقم مستخدم مذكور في `03-الحالة-والمعلق.md`.
2. **كل مشروع في مجلده الخاص** داخل مجلد `ayman` على OneDrive الخاص بالمستخدم. مجلد هذه المنصة: `ayman/المرجع الفني/`.
3. قل **«إنهاء العمل»** لا «نهو».
4. الخط **Tajawal** إلزامي (معتمد من التجمع) — لا تغيّره.
5. **الأسرار (كلمات المرور، المفاتيح، الرموز) لا تُكتب في كود الموقع أبداً** ولا في مستندات المشروع؛ تُحفظ في GitHub Secrets وفي ملف `.env` محلي فقط. اطلبها من المستخدم عند الحاجة.
6. لا تسأل أسئلة كثيرة؛ اعرض رأيك المهني واقترح الخيار الموصى به ثم نفّذ عند الموافقة.
7. قبل كل نشر: فحص صياغة كل ملفات JS (`node --check`)، واختبار محلي بالمحاكي، ثم النشر والتحقق من نجاح GitHub Actions وقراءة سجل الترحيلات.
8. الردود بالعربية الفصحى المبسطة؛ الشروحات للمستخدم تكون عملية ومختصرة، ونتيجة كل تحديث تُشرح له بما يلاحظه هو على الموقع لا بالتفاصيل التقنية.

## كيف تبدأ محادثة جديدة بأقل تكلفة؟

1. اقرأ هذا الملف و`02-النشر-والاختبار.md`.
2. استنسخ المستودع في مساحة العمل: `git clone https://github.com/sayahmotlaq/ahc-projects.git /home/claude/platform` (المستودع عام، لا يحتاج رمزاً للقراءة).
3. النشر يتم من **جهاز المستخدم (Mac)** عبر أدوات الجهاز المرتبط، حيث توجد نسخة `~/repo` تحمل صلاحية الدفع أصلاً — لا تحتاج إعادة إدخال أي رمز.
4. إذا احتجت اختباراً محلياً لقاعدة البيانات أو الاتصال بـ Supabase، اطلب من المستخدم بيانات الاتصال (لا تخمّنها).
5. أعمل التعديل → اختبر → أنشئ `updateN.tgz` برقم جديد → انشر → تحقق → اشرح للمستخدم.
