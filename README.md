# منصة إدارة مشاريع تجمع الأحساء الصحي
إدارة الخدمات الفنية — قسم المشاريع. المرجع الفني الموحد، جداول الكميات، ومتابعة المشاريع.

- `site/` الواجهة (تُنشر على GitHub Pages).
- `supabase/migrations/` مخطط قاعدة البيانات (يُطبَّق تلقائياً عند كل نشر).
- `data/reference.json` بيانات المرجع الفني (تُرفع تلقائياً؛ التعديلات اليدوية من داخل المنصة محمية).
